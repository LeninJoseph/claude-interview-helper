## How to approach any coding question (UMPIRE)

1. **U**nderstand — restate, ask about input size, edge cases (empty, duplicates, negatives).
2. **M**atch — which pattern? (sorted → binary search / two pointers; top-k → heap; shortest path → BFS…)
3. **P**lan — say the brute force + its complexity, then the optimised approach.
4. **I**mplement — clean code, good names.
5. **R**eview — walk through an example by hand.
6. **E**valuate — time & space complexity, trade-offs.
